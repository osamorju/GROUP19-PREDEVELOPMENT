# Project Contributions

This document records the work completed by each project member. It should be
updated with accurate information and evidence from GitHub or other agreed
project records.

## How to Update This Document

1. Add one row for every project member.
2. Describe work that was actually completed.
3. Link to commits, pull requests, issues, tests, or documents as evidence.
4. Ask each member to review their entry.
5. Do not include passwords, access tokens, private messages, or other
   sensitive personal information.
